# Theme Songs – Library Selection (Jellyfin 10.11)

Fork of [danieladov/jellyfin-plugin-themesongs](https://github.com/danieladov/jellyfin-plugin-themesongs).

## Changes
- Configure precisely which TV libraries are scanned with checkboxes in plugin settings.
- Each query is restricted to the selected Jellyfin library ID; unselected streaming libraries are not scanned.
- **No libraries selected means no scanning**, including after an upgrade.
- Per-run download, failure and skip counts in Jellyfin's logs.

## Build and publish
1. In GitHub Actions, enable workflows for this fork if prompted.
2. Run **Build and publish Jellyfin Theme Songs** with **Run workflow**.
3. Once successful, add this URL under Jellyfin → Dashboard → Plugins → Repositories:
   `https://raw.githubusercontent.com/joshualh/jellyfin-plugin-themesongs/master/manifest.json`
4. Upgrade the existing Theme Songs plugin, restart Jellyfin, then select only the downloaded TV library in Theme Songs settings. Do not install duplicate plugins with the same ID.

The release manifest and DLL are generated by the GitHub Actions workflow, **not** by committing the source alone. The plugin targets Jellyfin 10.11 (.NET 9).
